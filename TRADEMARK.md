# Trademark Policy

This policy explains how the **AI Accelerator** and **AIAC** names, logos, and related branding may be used.

This document is not legal advice. If you need formal legal interpretation, consult a qualified attorney.

## Scope

This policy applies to:

- the project names: **AI Accelerator** and **AIAC**
- project logos, icons, and visual brand assets
- product naming and branding references in forks, packages, and services

## Ownership

The project maintainers retain control over project branding and associated marks.
Use of source code under Apache 2.0 does **not** automatically grant rights to use project trademarks beyond this policy.

## Allowed Uses

The following uses are generally allowed without prior written approval:

1. Accurate, descriptive references to the project in articles, talks, tutorials, and comparisons.
2. Statements such as "built with AI Accelerator" or "compatible with AI Accelerator" when true.
3. Internal or personal use of project names/logos when there is no implication of official endorsement.
4. Unmodified redistribution of this project where branding remains truthful and non-deceptive.

## Not Allowed Without Permission

The following uses require explicit permission from maintainers:

1. Using AI Accelerator/AIAC names or logos in a way that implies official endorsement, sponsorship, or partnership.
2. Using project branding for commercial services, hosted products, or paid offerings in a misleading way.
3. Registering confusingly similar names, domains, package names, or social handles.
4. Modifying project logos and presenting modified logos as official branding.
5. Presenting a fork as the official AI Accelerator project.

## Forks and Derivatives

You may fork and modify the code under Apache 2.0.

If your fork materially diverges:

- use a distinct project name and branding
- clearly state that your project is an independent fork
- avoid names or logos likely to confuse users into believing it is the official project

## Package and Distribution Naming

If you publish plugins/extensions/integrations:

- choose names that avoid confusion with official distributions
- do not publish packages that appear to be the official AI Accelerator package unless you are an authorized maintainer

## Reporting Misuse

If you believe project trademarks are being misused, report it via:

- GitHub Discussions: https://github.com/AyoubArdem/AI_Accelerator/discussions

Include links, screenshots, and a short explanation of the suspected misuse.

## Policy Updates

Maintainers may update this policy at any time.
Continued use of project trademarks after updates implies acceptance of the updated policy.
